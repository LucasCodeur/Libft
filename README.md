# Libft

## Présentation

**Libft** est le premier projet du cursus **42**.

L’objectif est de créer une bibliothèque personnelle en **C**, en réimplémentant une partie des fonctions classiques de la libc et en développant des fonctions utilitaires réutilisables dans les futurs projets.

Cette bibliothèque constitue ensuite une base réutilisable pour plusieurs projets du cursus 42.

## Objectifs

* Réimplémenter des fonctions classiques de la libc.
* Manipuler les chaînes de caractères et la mémoire.
* Développer des fonctions utilitaires réutilisables.
* Implémenter et manipuler des listes chaînées.
* Organiser un projet C sous forme de bibliothèque.
* Comprendre la compilation et la création d’une bibliothèque statique.

## Fonctionnalités

La bibliothèque contient notamment des fonctions pour :

* **Caractères** — tests et conversions.
* **Chaînes de caractères** — longueur, copie, comparaison, recherche, concaténation, découpage...
* **Mémoire** — allocation, copie, déplacement et comparaison.
* **Conversions** — conversion de chaînes en nombres.
* **Allocation dynamique** — création et manipulation de chaînes.
* **Listes chaînées** — création, ajout, suppression et parcours de maillons.

## Compétences développées

* **C**
* Pointeurs
* Gestion de la mémoire
* Allocation dynamique
* Manipulation de chaînes
* Structures de données
* Listes chaînées
* Gestion des cas limites
* `Makefile`
* Bibliothèques statiques
* Debugging

## Ce que j’ai appris

Libft m’a permis de renforcer mes bases en **C** et de mieux comprendre le fonctionnement des fonctions couramment utilisées dans les programmes.

Le projet m’a également appris à écrire du code **modulaire et réutilisable**, avec une attention particulière portée aux pointeurs, à la gestion de la mémoire et aux différents cas limites.

## Overview

**Libft** is the first project of the **42 curriculum**.

The goal is to build a personal **C library** by reimplementing part of the standard libc functions and developing additional utility functions that can be reused in future projects.

The library then becomes a reusable foundation for several projects throughout the 42 curriculum.

## Objectives

* Reimplement common libc functions.
* Manipulate strings and memory.
* Develop reusable utility functions.
* Implement and manipulate linked lists.
* Structure a C project as a library.
* Understand compilation and static library creation.

## Features

The library includes functions for:

* **Characters** — character checks and conversions.
* **Strings** — length, copy, comparison, search, concatenation, splitting...
* **Memory** — allocation, copying, moving and comparing memory areas.
* **Conversions** — string-to-number conversions.
* **Dynamic allocation** — string creation and manipulation.
* **Linked lists** — node creation, insertion, deletion and traversal.

## Skills Developed

* **C**
* Pointers
* Memory management
* Dynamic memory allocation
* String manipulation
* Data structures
* Linked lists
* Edge-case handling
* `Makefile`
* Static libraries
* Debugging

## What I Learned

Libft allowed me to strengthen my **C fundamentals** and better understand how commonly used programming functions work internally.

The project also taught me how to write **modular and reusable code**, with particular attention to pointers, memory management and edge cases.
